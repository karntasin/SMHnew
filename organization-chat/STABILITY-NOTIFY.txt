อัปเดต: ชื่อซ้ำ / ความเร็ว / แจ้งเตือน (2026-08-24)
============================================================

สิ่งที่แก้
--------
1) ชื่อซ้ำ
   - GAS: รวม user ที่ lineUserId ซ้ำ (เก็บตัว login ล่าสุด)
   - Login แล้วอัปเดตชื่อ/รูปเดิม ไม่สร้างแถวใหม่
   - UI: ถ้าชื่อซ้ำ แสดงแผนก + #รหัสท้าย เช่น "สมชาย · IT · #A4F2"

2) ความเร็ว / ความเสถียร
   - API ใหม่ action=poll รวม unread + conversations + ข้อความใหม่
   - โหลด users map ครั้งเดียวตอนดึง conversations
   - ส่งข้อความแบบ optimistic (ขึ้นทันที แล้ว sync)
   - Poll 2.5 วินาทีตอนเปิดแชท / 8 วินาทีตอนอยู่หน้ารายการ

3) แจ้งเตือนข้อความใหม่
   - Toast มุมบน + เสียงสั้น ๆ
   - Badge แดงต่อรายการแชท + รวมด้านบน
   - Browser Notification (เมื่ออนุญาต และอยู่พื้นหลัง)


Deploy
------
A) Google Apps Script
   - Copy ไฟล์ organization-chat/Code.gs ทั้งไฟล์ไปวางทับ
   - Deploy → Manage deployments → Edit → Deploy

B) Cloudflare Worker
   cd organization-chat
   npx wrangler deploy


ทดสอบ
------
1. เปิด LIFF ใหม่ 2 บัญชีชื่อเหมือนกัน → ต้องเห็น #รหัสต่างกัน
2. ส่งข้อความ → ขึ้นทันทีฝั่งผู้ส่ง
3. ฝั่งผู้รับ → toast + เสียง + badge
